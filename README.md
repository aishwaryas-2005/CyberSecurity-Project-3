# Cyber Security Project 3 – Phishing Awareness Analysis

This project is based on DecodeLabs Cyber Security Project 3.

## Objective
Analyze sample emails/messages and identify phishing attempts by:
- identifying suspicious links or keywords
- listing red flags
- explaining why a message is unsafe

## Project files
- `phishing_analyzer.py` – Python program
- `sample_messages.csv` – sample messages for analysis
- `analysis_report.md` – sample analysis and findings

## How to run
1. Install Python 3.
2. Open a terminal in this project folder.
3. Run:
   `python phishing_analyzer.py`
4. Enter an email/message when prompted.

The program is an educational phishing-awareness tool. It performs rule-based analysis and does not open or visit links.
